# Streamstats
Потоковый анализатор файлов формата JSONL и CSV, создающий статистический отчет на основе данных в файле.
## Использование
Команда для анализа данных в файле:
```bash
python -m streamstats analyze [--FILENAME] --format csv|jsonl
```
**Особенности:**
* Формат данных должен соответствовать образцу, иначе программа выдаст ошибку. 

**Образец:**    
timestamp: ISO 8601 format  
level: DEBUG | INFO | WARNING | ERROR | CRITICAL    
source: непустая строка     
message: строка
## Флаги
Чтобы задать конкретный файл для сохранения в него отчета: "--output PATH"  
Чтобы пропустить неправильные строки при обработке и вывести их номера: "--skip-invalid"
## Обработка ошибок
В случае возникновения ошибки (неподдерживаемый формат файла, неверное событие, неверная временная метка и т.д.) программа выводит сообщение в `stderr` и завершается с кодом `2`.
